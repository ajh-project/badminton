# 🏸 배드민턴 3D

**https://ajh-project.github.io/badminton/** · 2D 클래식: [classic.html](https://ajh-project.github.io/badminton/classic.html)

내 얼굴로 하는 3D 배드민턴. 컴퓨터랑, 한 화면 둘이서, **폰끼리 온라인 대전**.

- **경기 방식**: 🏆 실제 경기(21점 먼저 내면 게임 승리, 3게임 2선승, 11점 인터벌, 듀스 없음) / ⚡ 빠른 경기(11점 1게임)
- **컴퓨터 난이도**: 🐣 입문 · 🙂 보통 · 🔥 고수 · 👹 프로 (고수부터는 빈 곳을 노림)

- **온라인 대전**: 방 만들기 → QR·링크 공유 → 상대가 접속 (WebRTC로 기기끼리 직접 연결, PeerJS 공개 중계 서버는 처음 연결에만 사용). 같은 와이파이에서 가장 안정적
- **전체 화면**: 폰에서 시작하면 자동 전체 화면·가로 고정. 아이폰은 공유 → 홈 화면에 추가

- **캐릭터**: 남자/여자, 옷 색, **얼굴 사진** (사진은 기기 안에서만 쓰이고 업로드되지 않음)
- **시점**: 🎮 3인칭 · 👀 1인칭 · 📺 중계 (게임 중 `V`로 전환). 둘이서 1·3인칭이면 화면 좌우 분할
- **시야**: 🎯 자동 추적(셔틀을 고개로 따라감) 또는 🖐 직접 조작(PC는 화면 클릭 후 마우스, Esc로 해제 / 폰은 기울이기). `C`나 🎯 버튼으로 정면
- **샷**: 그냥 스윙 = 클리어, 앞으로 누르며 = 드라이브, 뒤로 누르며 = 드롭, 점프하며 높은 셔틀 = 스매시
- **서브**: 스윙을 짧게 탁 = 숏서브, 꾹 눌렀다 떼면 = 롱서브 (누르는 동안 점수판에 게이지). 사람은 자동 서브 없음
- **자동 스윙(쉬움)**: 랠리 중 이동만 하면 셔틀이 오면 알아서 휘두름 (서브는 직접)
- 셔틀콕은 실제처럼 공기 저항을 받아 날아감 (종단속도 기준 물리)

| | 컴퓨터랑 | 둘이서 P1 | 둘이서 P2 |
|---|---|---|---|
| 이동 | WASD / 방향키 | WASD | 방향키 |
| 점프 | Space | Space | 오른쪽 Shift |
| 스윙 | F · J · 클릭 | F | Enter |

폰은 가로로 돌리면 조이스틱 + 스윙/점프 버튼이 나와요. `?demo`를 붙이면 컴퓨터끼리 대결 (`&view=first|third|tv`).

```bash
npm install
npm run dev
npm run deploy
```
