# 🏸 둘이서 배드민턴

**https://ahnjonghyunn.github.io/badminton/**

한 화면에서 둘이 하는 배드민턴. 컴퓨터와도 할 수 있어요. 11점 먼저 내면 승리!

| | P1 (왼쪽) | P2 (오른쪽) |
|---|---|---|
| 이동 | A / D | ← / → |
| 점프 | W | ↑ |
| 스윙 | S | ↓ |

- 스윙만 → 높게 넘기기 · 앞으로 가며 스윙 → 드라이브 · 뒤로 가며 → 드롭
- 점프해서 높은 셔틀을 치면 스매시
- 휴대폰은 가로로, 화면 양쪽 버튼으로 조작
- `?demo`를 붙이면 컴퓨터끼리 대결

```bash
npm install
npm run dev
npm run deploy
```
